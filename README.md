# Developer Survey & Job Market Data Analytics | Python Portfolio

A structured collection of **22 Jupyter notebooks** covering data collection, cleaning, exploratory data analysis, and visualization. The notebooks are based on **IBM Skills Network guided labs**, with notebook-specific portfolio commentary where included.

> **Scope:** This is a collection of learning labs, not a single validated end-to-end production analysis. Notebooks may use different data sources and should not be interpreted as one continuous dataset pipeline.

## How to explore

1. Start with the notebook index above and open any `.ipynb` file directly on GitHub.
2. To run locally, install Jupyter and the packages specified in the notebook you want to execute.
3. Some labs retrieve data from external URLs or APIs; availability, credentials, and results may change.
4. The original notebook names and outputs have been preserved. Notebooks have **not** been re-executed or independently validated as part of this packaging.
